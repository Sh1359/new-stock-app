# 📲 Shazim অ্যাপ ফোনে ইনস্টল গাইড

## উপায় ১ — এখনই চালান (লাইভ প্রিভিউ)
1. Arena-তে **LIVE PREVIEW** (Shazim App) লিংকটি ফোনে পাঠান (WhatsApp/নিজেকে মেসেজ)।
2. ফোনের **Chrome** ব্রাউজারে লিংকটি খুলুন।
3. মেনু **⋮ → Add to Home Screen → Install** — ব্যাস! হোম স্ক্রিনে Shazim আইকন আসবে, ফুল-স্ক্রিন অ্যাপের মতো চলবে।
4. প্রথমবার ১০,৬৭২টি Excel স্ক্যান লোড হতে কয়েক সেকেন্ড লাগবে — তারপর পুরো অ্যাপ **ইন্টারনেট ছাড়াই** চলবে।

> ⚠️ প্রিভিউ লিংক অস্থায়ী। স্থায়ী লিংকের জন্য উপায় ২ করুন (মাত্র ১ মিনিট)।

## উপায় ২ — স্থায়ী লিংক (GitHub Pages, ফ্রি)
1. কম্পিউটারে খুলুন: `github.com/Sh1359/new-stock-app`
2. **Settings → Pages** (বাম মেনুতে)।
3. **Source:** `Deploy from a branch` → Branch: `arena/c1fcc741-new-stock-app` → Folder: `/ (root)` → **Save**।
4. ১–২ মিনিট পর লিংক পাবেন: **`https://sh1359.github.io/new-stock-app/`**
5. এই লিংক ফোনের Chrome-এ খুলে **⋮ → Add to Home Screen → Install** করুন।
